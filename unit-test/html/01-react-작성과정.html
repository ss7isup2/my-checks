React로 만드는 과정

상담 콘솔 시안을 front-react의 React 화면으로 옮긴 순서입니다. 화면을 먼저 영역으로 나누고, Vite 프로젝트에 컴포넌트를 올린 뒤, 개발 서버에 조회·수정·삭제 API를 붙였습니다.

1. 시안에서 나눈 영역

한 페이지 안에 정보가 많으므로, 시안의 자리 그대로 여섯 덩어리로 나눴습니다.

시안 위치React 컴포넌트데이터
상단 바TopHeader화면 고정. 로고, 채널 상태, 로그인 사용자
왼쪽 아이콘 메뉴IconRail화면 안에서만 선택 상태

2. 기술 선택

  • React 19와 TypeScript로 화면 상태와 서버 응답의 모양을 같이 맞춥니다.
  • Vite가 개발 서버와 빌드를 담당합니다. 별도 프레임워크 없이 이 화면 하나에 집중합니다.
  • 전역 상태 라이브러리 대신 React Context를 사용합니다. 상담 한 건과 여정 목록만 공유하면 됩니다.
  • API는 Express를 따로 띄우지 않고 Vite 플러그인으로 같은 출처의 /api에 붙입니다. 화면의 fetch가 그대로 동작합니다.
  • 저장소는 data/db.json 파일입니다. 새로고침 후에도 수정과 삭제가 남습니다.

3. 디렉터리

4. 만든 순서

  1. 프로젝트 뼈대. package.json에 React, React DOM, Vite, TypeScript를 두고 index.html이 src/main.tsx를 읽게 했습니다.
  2. 데이터 모양. 상담 세션은 Consultation, 고객여정 한 줄은 Touchpoint로 정의했습니다. 시안에 보이는 접수번호, 오류코드, 채널, 처리내용이 이 타입의 필드입니다.
  3. 정적 화면. 헤더, 아이콘 레일, 왼쪽 열, 상담 폼, 여정, 오른쪽 AI 열을 컴포넌트로 나눠 CSS Grid로 배치했습니다. 폭은 상단 52px 헤더 아래 아이콘 52px, 왼쪽 300px, 가운데 가변, 오른쪽 304px, 가장자리 32px입니다.
  4. 예시 데이터. 시안의 김지훈 상담과 여정 네 건을 data/seed.json에 넣었습니다. 파일이 없으면 서버가 seed를 db.json으로 복사합니다.
  5. API 플러그인. server/apiPlugin.mjs가 Vite의 configureServer와 configurePreviewServer에 미들웨어를 올립니다. /api로 시작하는 요청만 처리하고, 그 외 주소는 화면으로 넘깁니다.
  6. 화면 연결. CounselProvider가 처음 마운트될 때 상담과 여정을 함께 조회합니다. 상담 폼의 저장은 PUT /api/consultation, 여정의 추가·수정·삭제는 /api/touchpoints를 호출한 뒤 목록을 다시 읽습니다.
  7. 확인. 개발 서버를 띄운 뒤 화면 배치를 보고, 상담 수정과 접점 추가·수정·삭제·초기화가 db.json에 반영되는지 요청으로 확인했습니다.

5. 서버를 붙인 방식

브라우저는 같은 주소의 API를 호출합니다. 개발 중에는 Vite가 화면과 API를 함께 제공합니다.

브라우저  SessionPanel / JourneyPanel
    │  useCounsel()
    ▼
CounselContext  ── fetch ──▶  /api/consultation
                           └▶  /api/touchpoints
                                    │
                                    ▼
                          server/apiPlugin.mjs
                                    │
                                    ▼
                              data/db.json
src/api/client.ts의 BASE는 빈 문자열입니다. 업무 서버가 다른 주소라면 이 값만 바꾸면 화면 코드는 그대로 둡니다. 그때는 서버가 이 문서의 모듈 설명에 있는 경로와 JSON 모양을 제공하면 됩니다.

6. 실행

front-react 디렉터리에서 의존성을 설치하고 개발 서버를 실행합니다.

cd front-react
npm install
npm run dev

브라우저에서 http://127.0.0.1:5173 을 엽니다. 타입 검사와 정적 빌드는 npm run build입니다. API 파일 저장은 개발 서버와 npm run preview에서 동작합니다. 빌드 결과만 다른 정적 서버에 올리면 /api가 없으므로 화면의 조회가 실패합니다.

7. 화면에서 확인하는 순서

  1. 화면이 열리면 왼쪽 고객명과 상담 폼, 아래 고객여정이 서버 값으로 채워집니다. 여정 카드 하단의 서버 연동 줄에 마지막 요청이 표시됩니다.
  2. 처리내용을 고치고 저장을 누르면 상담이 수정됩니다. 고객명이나 연락처를 바꾸면 왼쪽 카드와 오른쪽 AI 카드의 이름도 저장 결과로 바뀝니다.
  3. 접점 추가로 여정을 만들고, 행을 선택한 뒤 수정 또는 삭제를 누릅니다. 삭제는 한 번 더 확인합니다.
  4. 초기화는 seed.json을 db.json 위에 다시 복사합니다.
  5. 채널 탭과 날짜는 이미 받아 온 목록을 화면에서 거릅니다. 서버를 다시 호출하지 않습니다.
