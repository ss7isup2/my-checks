화면 소스가 두 갈래인 이유

프론트는 front/ 앱 하나입니다. 그 안에 “주소마다 페이지가 바뀌는 상담 화면”과 “한 껍데기 안에서 탭으로 관리 화면을 여는 화면”이 같이 있습니다. Vue 파일, Pinia, axios를 쓰는 방식은 같습니다.

왼쪽 메뉴 + 페이지

상담 화면 ipron

로그인 후 위에는 헤더, 왼쪽에는 아이콘 메뉴, 오른쪽에는 지금 고른 페이지 하나가 있습니다.

메뉴를 누르면 주소가 /{테넌트}/notices처럼 바뀌고, 라우터가 페이지 컴포넌트를 갈아 끼웁니다.

폴더 front/src/ipron

탭으로 겹쳐 여는 관리 화면

pages/tabs

사용자, 권한, 코드, 캠페인, 평가처럼 설정 화면이 많습니다. 각 화면은 검색 폼과 표가 있는 관리 페이지입니다.

메뉴를 눌러도 브라우저 주소가 화면마다 바뀌지 않습니다. MainPage.vue가 탭을 추가하고, 탭 이름에 해당하는 Vue를 그립니다.

폴더 front/src/pages, front/src/components

라우터가 껍데기를 고릅니다

파일은 front/src/router/routes.js입니다.

주소레이아웃안에 들어가는 것
/{tenantName}/login 등 ipron/layout/PreAuthLayout.vue 로그인, 이메일 등록, 비밀번호, 2차 인증. meta.public: true라 토큰 없이 들어옵니다.
/{tenantName}와 그 하위 ipron/layout/PostAuthLayout.vue 상담 메인, 대시보드, 이력, 공지, 콜백, 상담사, 고객, 통계, 쪽지, 마이페이지. skipUIMode: true.
/tenant-management components/layouts/TraditionalLayout.vue 슈퍼 관리자·테넌트 관리자용 테넌트 관리. pages/TenantManagement.vue.
/traditional/... 같은 TraditionalLayout 헤더·사이드바·본문·푸터 4구역을 시험하는 라우트. 일부 자식은 pages/MainPage.vue를 그대로 가리키는 placeholder입니다.
/single-view/... SingleViewLayout.vue 사이드바 없는 탭형. 모바일용으로 주석이 달려 있고, 자식은 대시보드 placeholder 정도입니다.
/popup/... 팝업 전용 레이아웃 티켓 상세, 상담 스크립트, KMS 검색, 설문. 새 창으로 띄우는 화면.

상담원이 매일 쓰는 주소는 /{테넌트이름}/...입니다. /traditional과 /single-view는 UI 모드 전환용으로 라우트와 미들웨어(router/middleware/uimodeMiddleware.js)가 남아 있습니다. 모드 값은 스토어 uimodeStore와 백엔드 uimode 패키지가 갖고 있습니다. 상담 테넌트 라우트는 skipUIMode라 이 전환을 타지 않습니다.

둘 다 같은 방식으로 API를 부릅니다

페이지 또는 탭
→
Pinia 스토어
또는 페이지 함수
→
js/api/○○Api.js
→
boot/axios.js 의 api
→
/rest/api/v1/...

getHeaders()가 Authorization: Bearer ${localStorage.accessToken}과 date-format 헤더를 붙입니다. 날짜를 시분초까지 받아야 하면 getHeaders("yyyy-MM-dd HH:mm:ss")처럼 넘깁니다. 백엔드는 이 헤더로 날짜 문자열을 해석합니다.

API 파일은 도메인마다 하나입니다. front/src/js/api에 50개 남짓 있고, 상담 화면과 관리 탭이 같은 파일을 import 합니다. 공지 목록은 양쪽 모두 noticeApi.getNotices를 탈 수 있습니다. 화면 마크업만 다릅니다.

상태도 반쯤 공유합니다

스토어위치쓰는 쪽
authStorestores/authStore.js로그인 사용자, 권한 그룹. 양쪽.
tenantStorestores/tenantStore.js현재 테넌트 id, 서브도메인. 웹소켓 헤더에도 사용.
websocketstores/websocket.jsSTOMP 연결. 양쪽이 알림을 받을 수 있음.
codeStore, menuStorestores/공통 코드, 메뉴 원본. 관리 화면에서 많이 씀.
mainTabstores/mainTab.js관리 탭의 열린 탭 목록, 활성 탭, 닫기.
menuNamesStoreipron/stores/상담 화면 왼쪽 메뉴만.
consultationStore, ticketStore, iccChatStoreipron/stores/통화 카드, 티켓, 채팅. 상담 메인 전용.

이름이 겹치는 스토어가 있습니다. stores/consultationStore.js와 ipron/stores/consultationStore.js는 다른 파일입니다. import 경로를 끝까지 봐야 합니다.

폴더를 이렇게 읽으면 됩니다

폴더내용
front/src/boot앱이 뜨자마자 실행. axios, 라우터, 창 닫기 전 처리(beforeunload.js), 상담 허브(counsel-hub.js, counsel-flow-hub.js).
front/src/router주소 표와 로그인·UI 모드 가드.
front/src/js/api백엔드 URL 함수. 화면은 여기만 호출하고 axios를 직접 쓰지 않는 편이 맞습니다.
front/src/js/commonheader.js, menu.js(관리 탭 코드), errorHandler.js, 마스킹.
front/src/js/ipron소프트폰 상수 IpronCode.js, 상담 앱 상수.
front/src/components관리 탭이 쓰는 조각. campaign, ticket, common(표, 버튼, 입력).
front/src/layoutsMainLayout, 로그인·팝업 레이아웃.
front/src/ipron상담 화면 전용 페이지·레이아웃·컴포넌트·스토어·컴포저블.
화면을 고칠 때 파일을 찾는 순서 주소창을 봅니다. /{테넌트}/callbacks처럼 테넌트 바로 아래면 routes.js에서 그 path를 찾고, import된 ipron/pages 파일을 엽니다. 주소는 그대로인데 탭만 바뀌면 pages/MainPage.vue의 components 맵에서 메뉴 이름을 찾습니다.
