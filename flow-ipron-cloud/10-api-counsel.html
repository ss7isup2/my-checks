상담 화면에서 나가는 API

왼쪽 메뉴의 각 페이지와, 그 페이지가 그리는 자식 컴포넌트에서 front/src/js/api를 직접 호출하는 지점입니다. 버튼 글자는 템플릿의 @click이 그 함수를 가리킬 때 붙입니다. 스토어 파일 안에만 있고 화면이 직접 부르지 않는 함수는 전체 목록에 있습니다.

표 읽는 법 액션은 Vue 함수 이름입니다. HTTP와 URL은 그 함수가 부르는 api 파일의 주소입니다. 백엔드는 URL 접두사가 가장 길게 맞는 @RequestMapping 컨트롤러입니다. CRUD 화면은 컨트롤러 클래스에 메서드가 없어도 부모 BaseWebCrudController가 GET/POST/PUT/DELETE를 처리합니다.
