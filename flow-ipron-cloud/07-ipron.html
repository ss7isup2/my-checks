상담 화면은 페이지 하나 = 주소 하나

front/src/ipron은 상담원이 로그인해서 쓰는 화면입니다. 왼쪽 메뉴가 있고, 오른쪽은 라우터가 그린 페이지입니다. 페이지 파일은 짧고, 복잡한 조각은 ipron/components로 빠져 있습니다.

로그인 전과 후

PreAuthLayout은 헤더·메뉴 없이 가운데 폼만 둡니다. 페이지는 LoginPage, EmailRegistrationPage, PasswordChangePage, EmailVerificationPage, TwoFactorAuthPage, PasswordResetVerificationPage입니다. 모두 /{tenantName}/... 아래에 있어, 주소의 첫 조각이 테넌트 서브도메인입니다. 로그인 API에 그 값을 넘깁니다.

로그인이 끝나면 PostAuthLayout입니다.

<header><HeaderBar /></header>
<aside><SidebarNavigation /></aside>
<q-page-container>
  <router-view />   <!-- 여기만 페이지마다 바뀜 -->
</q-page-container>

이 레이아웃은 새로고침(F5, Ctrl+R)을 가로챕니다. 확인하면 소프트폰 소켓 window.websip.sockClose()를 호출한 뒤 새로고침합니다. 통화 중 실수로 페이지가 날아가는 것을 막기 위한 처리입니다.

왼쪽 메뉴가 생기는 과정

  1. SidebarNavigation이 authStore.roleGroup.entityId를 읽습니다. 권한 그룹이 없으면 메뉴를 요청하지 않습니다.
  2. permissionApi.getMenusByPermission(permissionId)로 그 그룹에 허용된 메뉴 배열을 받습니다.
  3. menuNamesStore가 서버 메뉴 code를 아이콘, 색, 경로로 바꿉니다. 표는 스토어 파일 안의 codeToKeyMap, codeToIconMap, codeToRouteMap입니다.
  4. 화면에 없는 코드는 메뉴로 나오지 않습니다. 서버에 메뉴를 추가해도 이 맵에 코드가 없으면 클릭 경로가 없습니다.

BILLBOARD외부 URL페이지 없음. 계정 id를 암호화해 전광판 주소를 엽니다.

알림·쪽지 메뉴에는 notificationStore의 건수가 뱃지로 붙습니다. 활성 메뉴는 현재 주소에서 테넌트 조각을 지운 뒤 pathToKeyMap으로 고릅니다.

전광판 클릭은 bridgetecApi로 암호화된 accountId를 받고, systemVariableApi로 URL을 읽어 새 창을 엽니다. 라우트 이동이 아닙니다.

페이지는 얇고, 컴포넌트가 화면입니다

상담 메인 ipron/pages/MainPage.vue는 RemoteConsultationLayout만 그립니다. 마운트 시 통화 카드가 없을 때만 consultationStore.resetAll()을 호출합니다. 통화 중 데이터를 라우트 왕복으로 지우지 않으려는 분기입니다.

공지 페이지는 검색 폼과 표를 조합합니다.

  • ipron/components/notice/NoticeSearchForm.vue
  • ipron/components/notice/NoticeTable.vue
  • ipron/components/notice/NoticeRegisterDialog.vue

콜백, 상담 이력, 통계, 고객, 쪽지도 같은 모양입니다. pages는 라우트가 가리키는 껍데기이고, components/{업무}에 폼·표·팝업이 있습니다. 통계는 탭 컴포넌트(InboundStatisticsTab, CounselorStatisticsTab 등)가 StatisticsPage 안에 나란히 있습니다.

소프트폰과 채팅은 페이지 밖에서도 살아 있습니다

전화 제어는 Vue 화면과 별도 클라이언트입니다.

  • ipron/services/ipronClient.ts, ipronClientV2.ts — 교환기(IPRON)와 말하는 서비스.
  • ipron/composables/ipron/useIpronClient.ts — 페이지에서 그 서비스를 쓰는 컴포지션 함수.
  • ipron/composables/softphone/useSoftPhoneState.ts, useSoftPhoneEvents.ts — 버튼 상태와 이벤트.
  • js/ipron/const/IpronCode.js — 상태 코드 상수.

채팅은 composables/iccchat/ICCChatAPI.js, useIccChatHttp.js와 스토어 iccChatStore입니다. HTTP로 방·메시지를 가져오고, 실시간 문장은 웹소켓 토픽을 같이 봅니다.

STT 문장 이력은 상담 이력 팝업 STTHistoryPopup.vue가 브리지텍 STT API를 ucid로 호출합니다. 통화 중 따라오는 문장은 /topic/stt/message 구독입니다. “저장된 문장 조회”와 “지금 들어오는 문장”의 경로가 다릅니다.

이 화면 전용 스토어

스토어보관하는 것
consultationStore연결 카드, 상담 진행 상태. 메인 페이지가 비어 있을 때만 초기화.
ticketStore현재 상담에 묶인 티켓.
notificationStore알림 수, 쪽지 수. 사이드바 뱃지.
menuNamesStore권한으로 걸러진 왼쪽 메뉴. 한 번 로드하면 initialLoaded.
assistantStore어시스턴트 요약·이상 징후.
iccChatStore채팅방과 메시지.

스토어는 “서버 데이터의 복사본”입니다. 새로고침하면 메모리 상태는 사라지므로, 페이지 onMounted에서 API를 다시 호출합니다. 권한 메뉴만 initialLoaded로 중복 호출을 막습니다.

페이지를 추가한다면

  1. ipron/pages/SomethingPage.vue를 만듭니다. 검색·표는 ipron/components/something/으로 나눕니다.
  2. routes.js의 /{tenantName} children에 path와 name을 넣습니다.
  3. menuNamesStore의 코드·아이콘·경로 맵에 서버 메뉴 코드와 같은 키를 넣습니다.
  4. 권한 그룹에 그 메뉴가 있어야 API 응답에 포함되어 왼쪽에 보입니다.
  5. 데이터는 js/api에 함수를 추가하고 페이지에서 호출합니다. 백엔드 URL은 FlowAppConstants와 같아야 합니다.
